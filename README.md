# 호모 루덴스

재미있고 즐겁게 가르치고 배우는 교사를 위하여.

게임식 수업 학습 정리, AI 보드게임 연구 노트, 게이미피케이션 선행연구 대시보드를 통합한 정적 사이트입니다.

## 구성

- `index.html`: 통합 홈
- `lesson-2026-10-27.html`: 게임식 수업 발표자료에서 추출한 2026-10-27 학습 정리. 인용 쪽수는 PDF 파일의 실제 페이지 기준입니다.
- `research.html`: 기존 Claude 아티팩트의 12개 연구 섹션과 논문 요약·번역
- `dashboard.html`: 원본 단일 HTML의 19개 학습·연구 메뉴
- `assets/`: 공통 스타일, 연구 노트 스크립트, Marked 4.3.0 및 MIT 라이선스

## 로컬 실행

```sh
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8765/ 를 엽니다. 별도 빌드나 서버 API가 필요하지 않습니다.

## 배포

GitHub Pages에서 main 브랜치의 루트를 게시합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 내부 링크는 저장소 하위 경로에서도 동작하는 상대 주소입니다.

## 데이터와 원본

학습 메모·체크리스트는 브라우저 localStorage에만 저장됩니다. 다른 기기·브라우저 또는 기존 file:// 파일의 학습 기록은 자동 이전되지 않습니다. 원본 대시보드가 참조하던 별도 PDF와 프로토타입 앱은 제공받은 단일 HTML에 포함되어 있지 않아 업로드하지 않았습니다. 배포에서는 로컬 PDF 링크를 숨기고, 초안은 포함된 본문을 HTML로 내려받도록 했습니다.

기존 연구 내용의 근거 수준과 확인 필요 표시는 유지했습니다. 원본 Claude 아티팩트: https://claude.ai/artifact/Y1YZNtj5bDF9ZYezLcDRba

오늘의 학습 출처: 강준구·조수연·조혜민·윤정숙·황지은, 「게임식수업 발표」, 제공된 PDF 42쪽. 발표자료의 요약과 추가 수업 적용 아이디어는 학습 페이지에서 구분합니다.

`sources/`와 `reports/`는 로컬 검토용이며 배포하지 않습니다. `scripts/build-notes.py`는 로컬 원본 스냅샷에서 연구 노트를 생성한 보조 스크립트입니다. 원본 파일은 변경하지 않았습니다.
